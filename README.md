# QQ群注册守卫

AstrBot 插件：玩家私聊机器人发送 `/注册`（自动生成随机密码）或 `/注册 密码`（自定义），插件用发送者 QQ 号作为游戏账号，校验该 QQ 仍在受管群内后写入 MySQL `user` 表；玩家可私聊 `/找回密码 新密码` 修改自己 QQ 对应账号的密码；玩家退群后自动封号，重新加群后可用 `/解封` 自助解封（自动解封为可选项，默认关闭），并提供定时群成员校验兜底。

## 功能

- 私聊注册：账号默认使用发送者 QQ 号。`/注册` 不带密码时自动生成一个符合规则的随机密码并私聊告知，同时提示用 `/找回密码` 修改；`/注册 密码` 可自定义。群聊中不接收/不显示密码，只引导私聊。
- 注册失败清晰提示：任何注册错误都会明确回复「❌ 注册失败：原因」并附上正确的注册方式；数据库异常不会把原始报错暴露给玩家。
- 找回密码：玩家只能私聊修改自己 QQ 对应账号的密码。
- 自助解封 `/解封`：玩家重新加入受管群、且账号处于封禁态即可自助解封（默认不校验封禁来源）；可选开 `unban_only_auto_banned` 收紧为「仅解本插件退群自动封的号」。
- 自动解封（默认关闭）：可选监听 OneBot `group_increase` notice，玩家重新加群时自动解封；需在配置里把 `auto_unban_on_rejoin` 打开才生效。
- 群成员校验：注册、找回密码、解封前调用 OneBot `get_group_member_info` 确认用户仍在至少一个受管群内。
- 退群封号：监听 OneBot `group_decrease` notice。
- 定时兜底：周期拉取群成员列表，连续缺席达到阈值后封号；依赖审计表记录插件注册过的 QQ。
- 审计表：记录注册、封号、解封等插件动作；解封安全判定也依赖它，建议保持开启。
- 配置化数据库连接：通过 AstrBot WebUI 插件配置填写。

## 要求

- AstrBot 使用 `aiocqhttp` / OneBot v11 适配器，例如 NapCat。
- OneBot 端需要能调用 `get_group_member_info` / `get_group_member_list`。
- 自动退群封号需要 OneBot 端转发群成员减少 notice。
- MySQL 用户库中存在 `user` 表，登录字段兼容 `Name` + `Password`，封禁字段为 `IsBan` 或 `bantype`。

## 配置

在 AstrBot WebUI 插件配置中填写：

- `database`: MySQL 用户库连接。
- `managed_group_ids`: 允许注册并受守卫的 QQ 群号列表。
- `password_min_length`: 密码最小长度，实际不会低于 8 位。
- `auto_ban_on_leave`: 是否收到退群事件立即封号。
- `auto_unban_on_rejoin`: 是否在重新加群时自动解封；**默认关闭**。
- `unban_only_auto_banned`: 解封是否校验封禁来源。true=仅能解本插件退群自动封的号；**默认 false（不限制，只要在受管群内即可解封）**。
- `periodic_check_enabled`: 是否启用定时兜底。
- `periodic_check_minutes`: 定时校验间隔。
- `periodic_miss_threshold`: 连续缺席多少次后封号。

## 命令

```text
/注册            （自动生成随机密码，私聊告知）
/注册 密码       （自定义密码）
/找回密码 新密码
/查注册
/解封
```

`/解封` 默认只要玩家在受管群内、且账号处于封禁态即可解封，不校验封禁来源。若把 `unban_only_auto_banned` 设为 true，则仅能解除本插件「因退群自动封」的号（依据审计表判定），管理员手动封的号会被拒绝并提示联系管理员。

## 安全说明

密码命令请在私聊中使用；如果玩家在群聊发送 `/注册` 或 `/找回密码`，插件只会提示去私聊，不会处理群聊中的密码。本插件按现有 QQSpeed GM 后台兼容方式写入 `Password` 字段。如果你的服务端支持密码哈希，应优先改造服务端登录链路后再改插件存储策略。

密码规则：至少 8 位，并且必须同时包含小写字母、大写字母、数字和标点符号。
